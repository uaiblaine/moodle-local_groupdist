Distribution log

Every applied distribution of this course, read back from its stored snapshot.

Prototype Both screens of the report. The run detail is paged on two axes — group sections, and participants inside each section — because a run can hold hundreds of groups and thousands of participants. The two searches filter live here exactly as the AMD module does against the audit web services; the paging bar, the search form and each section's "Show more" are plain links and a form first, so the report also works with JavaScript off. Group sections lay out three to a row on a wide container and fall to two, then one, as it narrows — driven by the container, so the block drawer does not break it. Each card opens with five participants, and the outcome badge shows only when the outcome is not the expected “written”.
